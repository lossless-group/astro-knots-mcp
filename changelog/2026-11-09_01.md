## Why Care?

Someone with a coding agent can now install Astro Knots into Claude Code or
Codex and get our patterns as skills, plus a check on every edit that stops
React and JSX habits before they land. The same checks run on a whole site
before it deploys, including the share images that iPhone previews got wrong.

## What's New?

- **`knot-check`**, the core. Source checks (banned frameworks, JSX patterns
  in `.astro`, `workspace:` links, LFM, Vitest), built-site checks (exactly
  one `og:image` with its six tags, twitter tags, absolute URLs, the image
  file matching its declared size and type, canonical, sitemap, `robots.txt`,
  `llms.txt`), a live `share` check that fetches a page as each app's
  crawler, and a `doctor`. Every rule says where, how to fix it, and why.
- **One hook for both harnesses.** Claude Code reports an edit's file path;
  Codex sends a patch. The hook reads both, checks just the changed files,
  and hands failures back to the model.
- **The link MCP**, a Worker with no storage or keys: `get_started`,
  `list_skills`, `get_skill`, `explain_check`, `share_cards`, and a
  copy-a-prompt page.
- **Plugin manifests** for Claude Code (`.claude-plugin/`) and Codex
  (`plugin.json`, `.agents/plugins/marketplace.json`). `claude plugin
  validate` passes.
- **Skills:** `start-an-astro-knot` (the setup playbook, including Ideogram
  and tall-first share images) and `knot-check`, plus eight copied from
  lossless-agent-skills.
- **The design system, spike then refactor.** `knot-check components` lists
  components missing from `/design-system`, open `@spike` markers, oversized
  pages, and raw colors or fonts outside the theme files, all as warnings so
  spiking stays free. The Claude Code plugin ships a `component-refactorer`
  agent that refactors an approved spike back into components and onto the
  theme without changing what it shows. Two new skills come with it:
  `spike-then-refactor-into-components` and `maintain-design-system-page`.
- **39 tests**, covering every rule, both hook payload shapes, and the Worker.

## Calibration

Run against five of our own sites and the splash before anyone else sees it:

- **FantasyGM, live:** every crawler gets two `og:image` tags. The check
  catches the bug from [[iPhone-Share-Previews-Conflate-the-Tall-and-Wide-Banners]].
- **Our sites mostly fail on gaps our own skill calls required:** missing
  `og:image:secure_url`, canonical URLs, sitemaps, Vitest.
- **Two false alarms, fixed:** pages marked `noindex` (brand kits, design
  systems, OG render targets) are now skipped by the share checks.
  Fragments (`<>`) are a warning, not an error, because our own canonical
  `AstroMarkdown.astro` uses them. That needs a decision.

## Not yet

- The Worker isn't deployed, so the plugins don't include the MCP server yet.
- The Codex path hasn't run on a real Codex install: the patch format the hook
  parses, and the marketplace's `./` source path, are unverified.
- No starter site template; `start-an-astro-knot` builds from `create astro`.
- No share-card edge layer yet: static default only.
